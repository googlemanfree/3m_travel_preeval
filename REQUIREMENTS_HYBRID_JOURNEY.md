# Exigences Complètes - Parcours Client Hybride 3M Travel & Services

## Vue d'ensemble
Parcours client hybride (en ligne + agence physique) pour réduire les déplacements non nécessaires des clients à l'étranger.

## Agences Physiques
- **Douala** : Adresse à confirmer
- **Yaoundé** : Adresse à confirmer

## Phases d'Implémentation

### Phase 1 : Page Résultat après Wizard
- Checklist dynamique selon pays et type de visa
- 2 boutons : "Déposer mes documents en ligne" + "Prendre rendez-vous en agence"
- Affichée après étape 3 du wizard

### Phase 2 : Module de Paiement (PRIORITAIRE)
- Moyens : Orange Money, MTN Mobile Money, Carte bancaire (Visa/Mastercard)
- Boutons sous chaque formule tarifaire
- Génération automatique reçu PDF après paiement
- Formules : Règlement Intégral, Échelonné Flexible, Permis Garanti

### Phase 3 : Prise de Rendez-vous en Agence
- Formulaire : agence (Douala/Yaoundé), date/heure, coordonnées, pays, type visa
- Confirmation email/WhatsApp avec adresse agence + liste documents originaux

### Phase 4 : Suivi Dossier Public (PRIORITAIRE)
- Accès sans compte : numéro dossier + email/téléphone
- Statuts : Reçu → En vérification → Complet → Déposé → En traitement → Décision → Disponible
- Affichage temps réel

### Phase 5 : Notifications Automatiques
- Email + WhatsApp à chaque changement statut
- Relance automatique documents manquants

### Phase 6 : FAQ Enrichie
- "Dois-je me déplacer ?" → Optionnel (en ligne ou agence)
- "Où sont vos agences ?" → Adresses Douala/Yaoundé
- "Que se passe-t-il en cas de refus ?" → Lien Permis Garanti

### Phase 7 : Back-Office Agence
- Dashboard dossiers (filtre : statut, pays, mode dépôt)
- Calendrier rendez-vous partagé
- Export CSV reporting mensuel

## Fonctionnalités Complémentaires
- Barre de progression dossier en temps réel
- Bouton demande rappel téléphonique instantané
- Galerie visas accordés (preuve sociale)
- Calculateur budget frais officiels
- Décharge documents remis
- Facture paiements clients
- Traçabilité documents (en ligne vs scanné agence)
