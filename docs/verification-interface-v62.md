# Vérification d’interface — v62

Les captures mobiles de l’accueil, du formulaire d’assurance et de la page vols confirment que les zones principales restent lisibles dans une largeur de 390 px. La progression d’assurance est visible avant les champs, avec les quatre jalons voyageur, voyage, voyageurs et confirmation.

Les captures bureau confirment l’identité `3M Travel & Services` dans le héros, ainsi que l’intégration de la demande de devis sous la recherche de vols. Les champs du devis sont affichés sans remplacer le moteur de recherche ni le planificateur de voyage existants.
